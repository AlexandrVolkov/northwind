# Работа над Northwind

- Целевая версия движка — **Godot 4.7.2 stable, .NET / C#**. Точная версия записана в `.godot-version`; это метаданные проекта, а не механизм автоматической установки движка.
- Пишите и проверяйте изменения под этой версией. Перед проверками вызовите `<godot> --version`; если команда `godot` указывает на другую версию, используйте полный путь к 4.7.2. Не меняйте целевую версию без запроса пользователя.
- В `project.godot` тег `config/features` задаёт ветку API `4.7`, а не номер исправления `4.7.2`. Рендерер проекта — GL Compatibility.
- Код игры и интерфейса пишите на C#. Данные конфигурации остаются в JSON, конвертеры ресурсов — на Python. GDScript-версии удалены, не создавайте параллельную реализацию.
- Нужны .NET SDK 8 (см. global.json), Godot.NET.Sdk 4.7.2 и **.NET-редактор** Godot. Standard-редактор не запускает C#-проект.
- Для C#-изменений: `dotnet build`, затем `<godot-dotnet> --headless --path . tests/TestRunner.tscn -- simulation`. С импортированными ресурсами также выполните `<godot-dotnet> --headless --path . tests/TestRunner.tscn -- scene`; графические изменения проверяйте с графическим рендерером.
- Для изменений конвертеров: `python -m unittest discover -s tests -p 'test_*.py'`.
- Оригинальные ISO, EXE и импортированные ресурсы не добавляются в Git. Ресурсы создаются локально по README.
- Демонстрационные правила не выдавайте за восстановленные. Сохраняйте неизвестные поля и фиксируйте доказательства в docs/.
