# Бой: удар, урон, жизненные показатели

Урон, здоровье и темп ударов в схватке теперь исходные: здоровье — байт OBE[19] записи (ополченец 10, предводитель 50, замок 127), максимум — OBE[1A], урон — формула BFC9 с защитой DAT[44], удар наносится анимацией в исходный момент. Временные `health`/`damage`/`cooldown` из `data/skirmish.json` для расчёта больше не используются. Выбор цели, ИИ и полёт снарядов пока временные.

Адреса — LE:1 и `ARMY__00.WRK` (общий набор эффектов).

## Как наносится удар

1. Анимация атаки (945E) в момент удара создаёт **объект-эффект** (9727) типа DAT[70] атакующего в точке перед ним: координаты + знаковые смещения DAT[60..6F] по направлению. Бит 7 типа означает набор армии 0; у ополченца, рыцаря, предводителя и всадника это 128 → армия 0, тип 0.
2. Таблица типов эффектов — хвост файла DAT после шаблонов, записи по 7 байт: ширина, высота, смещение обработчика в WRK (u32), флаг. Эффекты хранятся в массиве `[6B2]` записями по 22h байта и обновляются циклом 96CD.
3. Эффект «удар» (`ARMY__00.WRK 4F3`, AH=0):
   - **атака = 5 + ((OBE[16] + 1) >> 6)** — растёт с опытом атакующего (байт +16, 0…127, т.е. 5…7);
   - 982B ищет объект в клетке точки удара в плоскости эффекта, с проверкой попадания в область DAT[3]/[4]; объекты с DAT.flags & 8000 не поражаются. **Владелец не проверяется** — удар по своему, оказавшемуся в точке, тоже проходит;
   - BFC9 наносит урон; при успехе играется звук 0 (или 1 для целей с DAT.flags & 10) и эффект становится анимацией искр (тип 4/5, 8 кадров по 2 такта). Промах освобождает эффект.

Стрелковые эффекты (тип 2 и др., `ARMY__00.WRK 762`) используют ту же атаку и передают в BFC9 вид удара = действие стрелка; полёт снаряда не перенесён.

## Формула урона, BFC9 (FS 119)

```text
если цель мертва (i8 OBE[19] ≤ 0) — нет попадания
OBE[17] = (OBE[17] & E0) | (вид << 3) | 1           ; отметка попадания
d = атака − DAT[44] цели                              ; защита
если атака > защиты (беззнаково): урон = d
иначе: k = u8(2 − d); если k > 4 — нет урона;
       иначе с вероятностью 1/k урон = 1               ; d=0 → 1/2, −1 → 1/3, −2 → 1/4
OBE[19] = max(OBE[19] − урон, 0); OBE[17] |= 2
```

Защита DAT[44]: ополченец/лучник/рабочий 0, рыцарь 2, предводитель и башни 3, здания 4. Ополченец (атака 5) убивает ополченца за 2 удара, рыцаря (5 − 2 = 3) — за 4, по зданию бьёт по 1.

## Жизненные показатели, 90E9

Общий префикс каждого юнита перед диспетчером действий (8227):

- OBE[19] ≤ 0 → путь смерти 95D3: звук гибели DAT[A7] (если ещё не «давно мёртв»), затем посмертная анимация A4DF; при DAT.flags & 100000 — особая ветвь 12D08.
- Живые (без DAT.flags & 10): **регенерация** `min(OBE[16] >> 5, OBE[1A] − OBE[19])` каждый такт — ветераны (опыт ≥ 32) лечатся сами; **кровотечение**: при здоровье ≤ 2 с шансом 1/32 −1.
- В покое раз в 256 тактов **отдых**: +¼ здоровья, но не выше DAT[45].
- При здоровье ≤ 2 (не в действии 3) — **бегство** 8E0E в случайную клетку карты. Также бегство при OBE[17] & 1A = 1A.
- Недостача здоровья ≥ 4 — голос раненого DAT[A3] (A416).
- Раз в 256 тактов с шансом 1/8 **опыт** растёт: `OBE[16] + 2 − (OBE[16] >> 6)`, при переполнении знака — 127.
- В покое: если DAT[58 + класс местности & 7] = 0 и в нижней плоскости нет опоры — гибель.

RNG: первый поток 9E41 (`[19EB]`), второй 9E55 (`[19EC]`), общая таблица 256 байт.

## Цикл атаки воина, 843E / 8EC7

Действие 3 воина (таблица WRK 0000 → FS F5 → 843E) в фазе 1 повторяет:

1. **8ABF** — жива ли цель OBE[1C]: состояние должно быть выше DAT[46] цели. У зданий это порог разрушения (замок 20): ниже него здание считается разрушенным, удары прекращаются. При гибели цели атакующий с опытом < 64 получает `DAT[76] цели / 4` опыта (ополченец 20 → +5, рыцарь 30 → +7, предводитель 96 → +24).
2. **8B5E** — досягаемость: «пробивная сила» DAT[71] атакующего должна превышать защиту цели (ополченец 5 > здание 4); плоскость цели — бит маски DAT[74]; расстояние `((зазор 9B86 + 15) >> 5) + 1` клеток — не больше DAT[72] (ополченец 1, лучник 7) и не меньше DAT[73] + 1; цель на воде (класс 1) дальше 48 px недосягаема. Слишком далеко — движение к клетке цели (8CBB), слишком близко или недопустимо — действие заканчивается.
3. **8AF4** — ворота удара: OBE[2F] растёт каждый такт до `DAT[75] − hi8(DAT[75] · опыт)` (ополченец 4, лучник 15 тактов; опытные бьют чаще).
4. **8BEA** — ожидание покоя и поворот к цели, затем **8C7C** — запрос удара (состояние 3, OBE[22]=FF — цель-объект).
5. Анимация удара (9210/93DF..9406 для цели-объекта: координаты цели в OBE[28]/[2A], слой в OBE[27]) на прогрессе DAT[4E] вызывает 945E: эффект DAT[70] в точке перед воином, сброс OBE[2F].

## Подключение к схватке

`Skirmish.Strike` применяет BFC9 с исходной атакой; `TickVitals` выполняет 90E9 каждый такт (смерть убирает объект, бегство ведёт к случайной клетке через маршрут). `AttackStep` исполняет пункты 1–5, `ResolveImpact` — эффект удара в исходной точке (982B → BFC9), поэтому удар может задеть и того, кто оказался в точке удара. Мостами остаются: выбор цели и ИИ, движение к цели маршрутом Godot, фазы 0/2 действия 843E (8CF3, 8F70), стрелковые снаряды (попадание сразу по цели с исходной атакой), визуальные эффекты и звуки.

Мост схватки выставляет каждому идущему юниту состояние движения OBE[2D]=22 (как исходный код), поэтому правило гибели на местности проверяет только стоящих юнитов, а не промежуточные точки шага. Утонуть может юнит, остановившийся на воде без опоры (моста) в нижней плоскости.
