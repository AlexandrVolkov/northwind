# Главное меню: исходные записи виджетов (C9, частичный срез)

`data/original_menu_widgets.json` получен `tools/menu_widgets_source.py` из
проверенного профиля NORWIND.EXE. LE:3 `ADBC..AF64` содержит девять записей
длиной 31h или 2Dh и завершается `FFFFFFFF` в `AF65`. Адреса и поля —
исходные, а не рассчитанные по внешнему виду экрана. Граф участка:
`tools/call_graph.py --start 18ED0 --end 19465 --root 18ED4 --root 19063
--root 190ED --root 19279` (локальный `build/menu-widget-call-graph.md`).

| LE:3 | Изображение | Прямоугольник | Callback | Параметры `+2C..` |
|---|---:|---|---|---|
| ADBC | 254 | 288,149,105,33 | 18F16 → 19279 (игра) | 1,1,0,1 |
| ADED | 257 | 238,177,105,31 | 18F16 → 19425 (выход) | 1,1,0,1 |
| AE1E | 260 | 260,268,117,43 | 18F16 → 193EB (авторы) | 1,1,0,1 |
| AE4F | 60 | 1,269,247,120 | 19063 (куст) | 30 |
| AE7C | 122 | 232,93,409,387 | 190ED (сова) | 51 |
| AEA9 | 173 | 0,0,640,125 | 19063 (свечи) | 30 |
| AED6 | 264 | 196,40,97,89 | 18F16 → 19436 (шар) | 1,1,0,1 |
| AF07 | 150 | 184,38,123,111 | 1923B (отдельный ввод) | 1,1,0,1 |
| AF38 | 204 | 0,0,64,108 | 19185 (песочные часы) | 50 |

Поля: `+04` тип, `+05` флаги, `+06` callback, `+0A` действие,
`+0E` scan code, `+14..+20` прямоугольник, `+24` начальный номер кадра,
`+28` текущий номер, `+2C..+2F` параметры. В записях 2Dh реально есть
только байт `+2C`; конвертер не читает за границу записи. `18ED4`
сравнивает байтовую разность таймера `[19E4] - widget[13h]` с DL,
обновляет `widget[28h]`, а при достижении порога сбрасывает его в ECX
и выставляет carry. Для куста и совы callback передаёт DL=3 и верхний
порог `sprite_base + parameter[0]`. Поэтому их параметры 30/51 — числа
кадров, а не задержки; частота шага — минимум три байтовых тика.
У свечей также используется 30 кадров. Сова после завершения 51-го кадра
вызывает `192EA` и меняет фазу меню `[A0AA]` на 2. Виджеты показываются
только при разрешённом бите `1 << [A0AA]` в флагах записи; `19063` проверяет
`+05` для обновления и `+04` для рисования. Это объясняет различие между
размером последовательности кадров и моментом её показа.

`18F16` ведёт более сложную подсветку табличек: состояние указателя
`widget[12h]`, проверка попадания через `18699`, три участка кадров
по параметрам `+2C..+2F` и вызов действия через `[widget+0A]` только
после завершения последнего участка. `19185` отдельно переключает
песочные часы и запускает `1CC1B`; полного цикла ещё нет в этом срезе.
Процедуры отрисовки `186C6/186F7`, проверки курсора `18699`, перехода
`192EA` и внешнее действие `1CC1B` не объявлены перенесёнными.
