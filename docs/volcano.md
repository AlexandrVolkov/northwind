# Вулкан (ARMY__04, WRK 0..9F)

Шаблон «Вулкан» (ARMY__04.DAT 0). Скрипт — `scripts/OriginalVolcano.cs`, сверка с x86 — `tools/verify_volcano.py` (1500 случаев, записанные службы), `tests/fixtures/volcano.json`, `tests/OriginalVolcanoChecks.cs`.

- `AH = 0` (создание): пауза +22 = (FS:109 & 0Fh) · 400h, фаза +15 = 0.
- `AH = 1` (обновление): в фазе 0 пауза отсчитывается до нуля, затем берётся новая пауза и фаза 1. В фазе 1 счётчик +22 убывает; на нуле скрипт заново создаётся. Пока второй случайный поток (FS:10D) не имеет бит 1Fh, вулкан выбрасывает эффекты 9727: тип 1 (слой 0, +1/+1Bh) каждые 20 обновлений счётчика, тип 0 (слой 1, +3/0) и четыре эффекта типа 2 (слой 1) в точке объекта.
- Службы FS:109 (9E41), FS:10D (9E55), FS:19 (9727) — записанные заглушки; в схватке первой карты вулканов нет.
- Остальные байты WRK (0A0..19A) — таблицы данных.
