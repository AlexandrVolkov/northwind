# Целевой движок: Godot 4.7.2 .NET / C#

Весь код прототипа и его Godot-проверки перенесены на **C#**. Нужны .NET-редактор Godot 4.7.2 и **.NET SDK 8**, обычный Standard-редактор не подходит. Конвертеры ресурсов остаются на Python; JSON и PNG сохраняют существующий формат.

## Зафиксированные версии

- `project.godot`: API 4.7, функция C#, GL Compatibility, сборка Northwind.
- `Northwind.csproj`: Godot.NET.Sdk **4.7.2**, TargetFramework **net8.0**, nullable-анализ включён.
- `global.json`: SDK **8.0.428**, разрешены более новые стабильные feature/patch SDK ветки 8.0. SDK необходимо установить отдельно; файл не скачивает его автоматически.
- `.godot-version`: 4.7.2; инструкции разработки — в AGENTS.md.

Официальный релиз: https://github.com/godotengine/godot/releases/tag/4.7.2-stable

Проверена Linux x86_64 сборка `Godot_v4.7.2-stable_mono_linux_x86_64.zip`. SHA-256 сверен с официальными метаданными:

```
129f82db7bafd54ae14bb5bb284041c73860e8c7a009a3a026ca5e946cbff247
```

Движок сообщает `4.7.2.stable.mono.official.ed1daf0bf`. Использован SDK 8.0.428. Первое восстановление NuGet требует сети.

## Проверки

```bash
dotnet build
godot --headless --path . tests/TestRunner.tscn -- simulation
# С предварительно импортированными ресурсами:
godot --headless --path . tests/TestRunner.tscn -- scene
godot --path . --audio-driver Dummy tests/TestRunner.tscn -- scene
python -m unittest discover -s tests -p 'test_*.py'
```

`godot` в этих командах должен быть .NET-редактором 4.7.2. Сборка C# не требует экспорта игры. Сцена TestRunner возвращает ненулевой exit code при провале проверки. Проверки модели выполняются внутри Godot, так как модель использует AStarGrid2D; зависимости на интерфейс и текстуры у неё нет.

Перенос не означает точное воспроизведение оригинальных правил: бой, ИИ и временная модель пока демонстрационные. История проекта до переноса доступна в Git. Экспорт и запуск на Windows/macOS ещё требуют отдельной проверки; для C#-экспорта нужны соответствующие шаблоны 4.7.2 .NET. Веб-экспорт C# не является поддерживаемой целью проекта.

Результат переноса на Linux: сборка без предупреждений и ошибок; 22 проверки симуляции, 9 интеграционных проверок сцены в headless и 10 в графическом режиме; отдельная проверка запуска без импортированных ресурсов; 11 Python-тестов. Импорт редактором проверен с `--quit-after 120`, чтобы завершилась инициализация .NET-редактора. Локальная AST-индексация Graphify обнаружила C#-код (198 узлов / 406 связей на момент проверки); экономия токенов этим не измерялась.
