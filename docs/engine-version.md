# Целевой движок: Godot 4.7.2 stable

Проект переведён с 4.6 на **Godot 4.7.2 stable, Standard / GDScript**. Дальнейшую разработку и проверку выполнять на этой версии. .NET-сборка и C# не требуются.

- `project.godot`: ветка API `4.7`, рендерер GL Compatibility. В `config/features` Godot использует major.minor; тег не фиксирует patch-версию.
- `.godot-version`: точная целевая версия `4.7.2`. Это метаданные, не автоматический установщик и не блокировка запуска других версий.
- `AGENTS.md`: инструкции для дальнейшей разработки и проверок.

Официальный релиз: https://github.com/godotengine/godot/releases/tag/4.7.2-stable

Для проверки использована Standard Linux x86_64 сборка `Godot_v4.7.2-stable_linux.x86_64.zip`. SHA-256 архива сверена с метаданными официального релиза:

```
cadd3204e728a35d3f13adb7fd0d7902636b79f6b95c40c265eb73b6c35329e4
```

Исполняемый файл сообщает `4.7.2.stable.official.ed1daf0bf`. Если команда `godot` запускает старую установленную версию, используйте полный путь к бинарнику 4.7.2 во всех командах из README.

## Результаты перехода

- Headless-импорт редактором: без ошибок скриптов/импорта.
- `tests/test_simulation.gd`: PASS.
- `tests/test_scene.gd`: PASS в headless и в графическом режиме, включая выбор, движение, конец хода, сброс и окно данных сценария.
- Визуально проверена отрисовка оригинальных тайлов, отрядов, миникарты и панели.
- 8 Python-тестов конвертера: PASS.

Проверки выполнены на Linux, OpenGL Compatibility, Mesa llvmpipe. Исправлений API GDScript не потребовалось. Экспортированные сборки и запуск на Windows/macOS на этом этапе не проверялись; для экспорта нужно устанавливать шаблоны экспорта именно 4.7.2.
