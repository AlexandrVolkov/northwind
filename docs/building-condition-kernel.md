# Два шага состояния здания, перенесённые в C#

Реализация: [OriginalBuildingRules.cs](../scripts/OriginalBuildingRules.cs). Основание — машинные инструкции известного NORWIND.EXE; значения ожидаемых результатов получены исполнением оригинала, без промежуточной Python-реализации правил. Общая карта загрузки: [executable-analysis.md](executable-analysis.md).

Это отдельные операции будущей симуляции исходных объектов. Демонстрационный бой их пока не вызывает. Полные строительство, ремонт, выбор целей, создание эффектов и время ещё не восстановлены. Байт состояния +0x19 не отождествляется с отображаемыми очками здоровья.

## Общий шаг увеличения состояния: C80D..C88B

Связь вызова подтверждена: у замка ARMY__02.DAT[2] обработчик WRK начинается с 0xfe. В режиме AH=1 он вызывает FS:0x41 → EXE 0xc88c. Эта функция выбирает ветвь по `OBE[0x14] & 7`; для значения 1 таблица WRK по 0x17f направляет выполнение на WRK+0x1bb. Оттуда FS:0x3d вызывает **EXE 0xc80d**. BL содержит бит 0x40 исходного OBE[0x14]; это ещё не установленное понятие паузы, поэтому параметр назван StateBit40.

Входные поля:

| Источник | Поле | Использование |
| --- | --- | --- |
| OBE +0x19 | Condition | Увеличиваемый байт состояния |
| OBE +0x16 | Counter | Счётчик вызовов, u8 с переполнением |
| OBE +0x0f | WorkFlags | Ненулевое значение включает платную ветвь |
| OBE +0x17 | ObjectFlags | Проверка флага 0x02 и маски 0x1a; смысл всех битов неизвестен |
| DAT +0x45 | Limit | Значение, при равенстве которому операция завершается |
| DAT +0x57 | Interval | Порог счётчика вызовов |
| DAT +0x8c/+0x90/+0x94 | Costs | Три u32 затраты шага |
| Запись владельца +0x18/+0x1c/+0x20 | Balances | Три u32 запаса; запись выбирается по OBE[3] со stride 0xf5 |

Названия ресурсов для этих трёх слотов ещё не установлены. Параметры реальных шаблонов ARMY__02:

| Шаблон | Limit | Interval | Costs |
| --- | --- | --- | --- |
| Замок, индекс 2 | 127 | 4 | (0,2,2) |
| Казарма, индекс 3 | 80 | 4 | (0,2,2) |
| Лесопилка, индекс 4 | 70 | 4 | (0,1,1) |

Точный порядок:

1. Бит StateBit40 или неподходящие ObjectFlags завершают операцию: WorkFlags=0x20, ZF=1, BL=1. Счётчик и запасы не меняются.
2. Счётчик увеличивается как байт. Пока он меньше Interval, возвращается ZF=0: действие продолжается без списания.
3. При ненулевых WorkFlags они заменяются на 1. Сначала проверяются **все три** запаса без знака. Если хотя бы одного не хватает, возвращается завершение с WorkFlags=0x20 и BL=1; частичного списания нет, но уже увеличенный счётчик сохраняется.
4. При достаточных запасах списываются три затраты. При исходных WorkFlags=0 эта ветвь полностью пропускается.
5. Счётчик сбрасывается. Только **после возможного списания** проверяется равенство Condition и Limit. При равенстве — завершение с BL=0; иначе Condition увеличивается как u8, действие продолжается с BL=1.

C# возвращает ContinueAction как инверсию ZF и Signal как исходный BL. Эти сигналы различаются: ожидание порога продолжает действие с BL=0, а нехватка запасов завершает его с BL=1. Их нельзя заменить одним признаком «готово».

Interval=4 означает четыре вызова от нулевого счётчика, а не четыре секунды или универсальных тика. Полная привязка команды ремонта из интерфейса к этому состоянию и способ первоначального задания WorkFlags пока не установлены.

## Применение повреждения одной цели: BE04..BE2D

Это хвост функции, которая предварительно выбирает шаблон цели. Предшествующий участок 0xbdcf проверяет список уже обработанных объектов: его нельзя забыть при дальнейшем восстановлении площадного повреждения.

В рассматриваемом хвосте сила воздействия берётся из глобального байта 0x1f41, защита — из DAT[0x44], исходная реакция — из байта 0x1f44. Последовательность:

- При знаковом значении Condition > 0 и `strength > protection` вычисляется разность. Из Condition вычитается разность; заём ограничивает результат нулём. В реакцию добавляется маска 0x02.
- При равенстве или меньшей силе состояние не уменьшается. Значения Condition 0x80..0xff проходят знаковую проверку как отрицательные и также не повреждаются этой ветвью.
- Во всех случаях младший байт ObjectFlags становится `(old & 0xe0) | reaction`; старший байт сохраняется. Даже отсутствие уменьшения состояния не означает отсутствие изменения флагов.

В C# это ApplyDamageTail. Способ расчёта входной силы, отношения владельцев, площадь, дедупликация целей, эффекты и смерть не входят в этот метод.

## Независимый эталон и проверки

[tests/fixtures/building-kernel.json](../tests/fixtures/building-kernel.json) хранит входные сетки, хэши источников и SHA-256 последовательностей результатов, полученных непосредственно из x86. В Git нет исполняемых байтов. Обычная проверка C# не требует копии игры или Unicorn.

| Проверка | Исполнений оригинала |
| --- | --- |
| Общий шаг: реальные параметры трёх шаблонов и синтетическая граница u32/u8, флаги, счётчики и запасы | 35 840 |
| Хвост повреждения: весь диапазон байта Condition, выбранные силы, защиты и флаги | 163 840 |

Генератор исполняет обе функции до настоящего ret, не пропуская вызовы и не подменяя ветви. Дополнительно проверяет сохранность прочих полей объекта и запаса соседнего владельца при операции обслуживания. C# перебирает те же входы и сравнивает хэши всех результатов с эталоном. На 199 680 комбинациях расхождений нет. Полный перебор всех возможных входных значений этим не заявляется.

Воспроизведение эталона из своей копии:

```bash
python -m pip install -r tools/requirements.txt -r tools/requirements-research.txt
python tools/verify_building_kernel.py --game "/путь/к/игре" --output build/building-kernel.json
```

Сравнение файла с tests/fixtures/building-kernel.json должно давать идентичные метаданные и хэши для исследованной версии. Проверки C# включены в режим simulation; отдельно:

```bash
dotnet build
godot --headless --path . tests/TestRunner.tscn -- original-buildings
```

Следующий шаг — связать запуск действия с интерфейсной командой, восстановить создание объекта и начальные WorkFlags/Condition, назвать ресурсные слоты и проверить полный цикл WRK с выбором кадров. До этого две точные операции не означают готовую систему строительства или боя.
