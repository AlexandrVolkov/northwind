# Орда Теймура (лагеря слота 4) — разбор, 22.11

Со слов пользователя: Теймур и его орда появляются на карте случайно, строят «шалаш», из которого выходит большая армия, идёт исследовать карту и со временем нападает, если становится многочисленной.

**Что нашёл в коде.** Первая карта держит в слоте 4 четыре объекта **«Лагерь»** (ARMY__00 шаблон 0, WRK 0..52). Их логика — LE:1 `11943..11B4D` (FS:131, вызывается из WRK AH=1), состояние в `+15`, таймер в `+23`:

| Состояние `+15` | Что делает |
| --- | --- |
| инициализация (WRK AH=0) | `+22` = направление от центра карты (0x800), `+23` = `2710h + 9E41` |
| **0** | таймер `+23` убывает; при отрицательном: если у участника `+5C ≠ 0` — таймер снова `2710h + 9E41`; иначе из дерева участника выбирается шаблон класса A08h (22E46: **«Шатер»**, ARMY__01 №18), ищется место у лагеря (10AD2, перенесён), создаётся здание в постройке (A758, `+14 = 81h`, `+1A = 1`, 43E5), вызывается `1E740` (**персонаж ИИ 4** копируется в блок ИИ участника: `+19FF`, `+1A14`, `+1A15` …), `+19F1` (сила ИИ) = 7D0h, `+5C` = 1, лагерь `+15 = 1` |
| **1** | `+23` растёт; раз в 1000h тактов участник получает по 1F4h (дерево, металл), 3E8h (золото), 50 (люди); пока у ИИ есть сила (`+19E9`) состояние держится, иначе лагерь возвращается в 0 с таймером 2710h — орда **возрождается** |
| **2** | сторожевые объекты вокруг (шесть направлений), переключение флагов `+27` у объектов лагеря |

Итак «случайное появление» — таймер `2710h + 9E41` каждого из четырёх лагерей; «шалаш» — «Шатер» ARMY__01; «большая армия, идёт исследовать, нападает» — уже перенесённый ИИ (патруль состояния 8 по разведанным клеткам, походы 7/8/9, набеги) с **характером 4**, питаемый ресурсами лагеря.

**Что нужно перенести** (порядок): (1) `OriginalCamp` — состояния 0/1/2 лагеря со сверкой Unicorn; (2) третья армия: схватка предполагает ARMY__02 (`TeamOfSlot`, `_templates.Armies["ARMY__02.DAT"]`, `_aiTemplates`, `_aiMakes`, имена шаблонов в `Rules.Units`, проверки по индексу `3 or 4 or 6…`): нужны ключи (армия, индекс); (3) данные ARMY__01 (кадры атласа, производители WRK AH=6, дерево ARMY__01.TRE, правила); (4) участник слота 4 в списке ИИ (`AiSlots`) с персонажем 4, отключённый до основания лагеря.
