# ИИ поселения (исследование)

Статус: **разбор начат, перенос не выполнен.** Адреса — LE:1. Ход ИИ одного компьютерного поселения — **2323A..23666**, вызывается из 1E85F вместе с 23667; ESI — блок состояния ИИ (`6BA + 1A35·n`, тот же, что статистика участника), `[ED2D]` — запись участника (97A + F5·n), `[ED20]` — тот же блок ИИ, `[ED2C]` — номер участника. На время хода счётчик `[ESI+1]` увеличен на 42h.

## Дань вассала (23244..232B4)

Если какое-то поселение — покровитель (отношение 4 в таблице +B9 вассала), то для золота (+20), металла (+18) и дерева (+1C) вассала: прирост с прошлого хода (`запас − снимок` в ИИ +1A28/+1A2C/+1A30) делится пополам — половина переходит покровителю, снимок обновляется. Это и есть исходная **дань**: 50% дохода.

## Поражение поселения (232BA..23383)

Раз в 256 ходов (`[ESI+1] & FF = 0`), если «сила» `+19F1` ≤ 1999: поселение помечается побеждённым (`+19E4 |= 2`), сбрасываются +19FF/+1A15/+1A34 и активность (+1A27 бит 0), очищается очередь сообщений; если сила не нулевая — каждому знакомому поселению отправляется сообщение 13h («Мы прекращаем все отношения!»), врагам засчитывается победа (+19FD, или +19FE при флаге 2).

## Дипломатические решения (23392..23549)

Раз в 128 ходов, после 23B10, для каждого другого поселения, которое ИИ «видит» (23A95: есть запись в списке планов +697 с этой целью) и чья сила `+19F1` > 1999, по отношению к нему:

| Отношение | Условие | Действие |
| --- | --- | --- |
| 1 — контакт | своя сила ≥ порога `+3D` | если «счёт обид» `[F149 + 4i]` > 200 — план 1/2 (1EB5C); иначе при пересечении областей поселений (23B6A) — план 2/3 с учётом союза/вассалитета (сообщения 0Ch/0Dh в очереди) |
| 2 — война | — | план 3 (атака) |
| 3 — союз | своя сила ≥ `+3D` и чужая `+6F` ≥ 200 | план 2 |
| 5 | своя сила ≥ `+3D`, нет флага 2 | при «обиде» > 200 — сообщение 5 «Объявляю войну»; иначе при пересечении областей — план 1 |
| 4 — вассал | своя сила > `+35` | сообщение 0Dh «Я больше не буду платить тебе дань» покровителю |

1EB5C добавляет запись в список планов ИИ (+697, 20 записей по 15h): режим (AL), цель (CL).

## Строительство и расширение (23551..2365B)

Раз в 1024 хода: если нет флага 2, ищется подходящее место рядом с замком (1ECA0/22E46 с маской 508h/F08h, случайное смещение двумя потоками RNG) и, если место свободно (10AD2, 22FE4, A758), ставится новое здание (`+14 = 81h`, `+1A = 1`, 43E5). При силе ≥ `+35` и без флага 1 в +77 — план 5 по объекту класса C08h (22E46) в список +34F.
