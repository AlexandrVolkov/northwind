# Башня (ARMY__02 №13) — 22.11

Башня — здание (флаг 8 в `DAT[40]`) с атакой: поэтому «строение» теперь определяется флагом DAT, а не нулевым уроном из таблицы правил (`SkirmishActor.Structure`).

**Атака** — служба FS:9D = LE:1 `CA7C` (WRK `0xCB9`, событие атаки; сверена с оригиналом через Unicorn: `tools/verify_tower.py`, `tests/fixtures/tower.json`, 4000 случаев, 75 выстрелов; службы D895 и 9727 записаны): счётчик заряда `+24` растёт до `DAT[75]` (10), счётчик `+23`; здание в состоянии «разрушено» (`+19 ≤ DAT[46]`) не стреляет; раз в 8 обновлений ищет врага (D895 в режиме «задет»: дальность `DAT[47]` = 8), при полном заряде стреляет: направление 9688 (8 сторон по знакам и отношению 2:1; таблица DS:19D7), точка выстрела — позиция + пара со знаком `DAT[60 + 2·направление]`, эффект `DAT[70]` = 82h — стрела WRK 593 (общая со стрелками лучников: `OriginalArrowRules`).

**В схватке:** башню строят из списка готового завода (кнопка «Башня», `BuildIndex(13, клетка)`), она рисуется оригинальными кадрами (ступени стройки `DAT[4A]` = 7). Стреляет только по тем, с кем война (дипломатия), так что игрок сначала объявляет её повторным приказом. **Не перенесено:** WRK-таблица событий башни кроме атаки (посетители с флагом `DAT[40] & 1000h` и счётчик `+22` до 32h/3Ch — LE:1 `CB77`, механика «захвата цели», её смысл не восстановлен), анимация выстрела (`+16 = 28h`), разрушение башни (руины), башни ИИ (ИИ строит их по правилам оригинала, но игровых правил построек ИИ для башни не проверено).
