# Сообщения и дипломатия (исследование)

Статус: **разбор начат, перенос ещё не выполнен.** Адреса — LE:1, данные — LE:3.

## Состояние участника

| Поле участника (97A + F5·n) | Источник | Смысл |
| --- | --- | --- |
| u32 +12 | SCN +0F (2EF1) | Маска владельцев, с которыми идёт война. D895 атакует только их (или цели с DAT-флагом 400000h) |
| +B9..+C8 | SCN +3A, 16 байт (2F60) | Отношение к каждому владельцу: 0 — не знакомы, 1 — контакт (F250), 2 — война (23A6E) |
| +34.. | очередь сообщений | 8 записей по 0Eh: тип (FF — свободно), u32 время, u32 срок, отправитель (+9), u32 параметр (+0A) |
| статистика +73 | 6BA + 1A35·n | Уменьшается на 2500 при объявлении войны без особого условия (F000) — вероятно, репутация |

На первой карте у всех поселений маска вражды и отношения нулевые: никто ни с кем не воюет и не знаком.

## Отправка и типы

**EDD5** (AL = тип, AH = получатель, BL = отправитель, EBP = параметр): если такого сообщения ещё нет (EE69), занимает свободную запись очереди получателя, ставит время `[1CA9]` и срок `время + срок типа` и сразу вызывает обработчик типа. Таблица типов — LE:3 `0EFB`, записи по 13h: u32 текст, u32 обработчик, u32 срок (512 или 1024), байты параметров.

| Тип | Текст (первая строка) | Обработчик |
| ---: | --- | --- |
| 0 | «Мы сдаёмся и надеемся на твою милость» | F154 |
| 1 | «Принимаю твою капитуляцию, но ты мне будешь платить дань» | F09C |
| 2 | «Мне нужна твоя жизнь!» | — (E65A) |
| 3 | «Обнаружен неизвестный народ!» | F250 |

## Что уже понятно

- **Первая встреча.** D895 при виде чужого юнита без контакта вызывает EDD5 с типом 3. F250 ставит отношение 1 у получателя и, если отправитель ещё не знает получателя, отправляет встречное сообщение типа 3.
- **Объявление войны.** F000: при отсутствии особого флага снижает статистику +73 на 2500, вызывает EEFA, взаимно устанавливает биты вражды (21459) и отношение 2 у обеих сторон (23A6E), затем EF3F.
- **Игрок объявляет войну приказом атаки** на объект чужого поселения (4F04..4F3B): первый такой приказ отправляет сообщение 93h (предупреждение), повторный по той же цели — тип 5 «Объявляю тебе войну».
- **Гибель героя** (44C0..4515): сообщение типа 0Eh игроку.

## Следующие шаги

1. EEFA, EF3F, обработка очереди по времени (E861, F645), отображение сообщений игроку и выбор ответа.
2. Решения ИИ: блок 23300..239C0 (много вызовов EDD5) — когда ИИ угрожает, объявляет войну, предлагает союз или сдаётся.
3. Капитуляция и дань (типы 0/1, F154/F09C), «Налог собран» (тип 9) — связь с данью и бунтом из [воспоминаний игрока](player-gameplay-notes.md).
4. После переноса убрать мост схватки «два поселения враждуют с начала»: по исходным правилам война начинается с объявления.
