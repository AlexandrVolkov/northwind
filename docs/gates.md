# Ворота (ARMY__02 #14)

Подтверждено по DAT/WRK: размер 2×1, плоскость 1, цена 50/100/150, DAT[4A]=6 стадий, команды «Открыть» / «Закрыть» / «Автомат» (слоты 2, 3, 4), WRK 0xD85: состояние +14 = 2/3/4 запускает службы FS:91 (открыть), FS:95 (закрыть), FS:C1 (автомат).

**Адаптер (не восстановлено):** службы FS:8D/91/95/C1 не перенесены. Открытые ворота освобождают клетки, закрытые занимают их; «Автомат» открывает ворота для своих юнитов в радиусе 2 клеток и закрывает, когда никого нет (юнит в проёме удерживает их открытыми). ИИ-ворота ведут себя так же, но по своей команде.

**Кадры:** в атлас попадают кадры 0..5 (74×56). Какой из них «закрыто/открыто» неизвестно: взяты кадр 3 (закрыто) и 5 (открыто) — догадка, проверить по оригиналу. Кадр 6 (35×14) и 7 в атлас не взяты, семантика неизвестна.
