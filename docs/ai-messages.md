# Сигналы отрядов ИИ A4C2 (C14)

Исследование исходного `NORWIND.EXE` исправляет предпосылку задачи:
`A4C2` **не выводит текст отряда**. Это обёртка позиционного звука
из банка `WORK.FX`. Тексты дипломатических сообщений проходят по
другому коду и описаны в [diplomacy.md](diplomacy.md).

## Путь вызова

`20071..20094` сначала проверяет количество бойцов отряда
`[EDI+22h] > 10`. При меньшем отряде ничего не запускает.
Иначе `1EAD8` получает блок ИИ по номеру участника `[EDI]`;
байт характера блока `+29h` выбирает строку таблицы LE:3 `F02E`
(шаг `0Ch`). Входное значение EAX — байтовое смещение столбца
`0/4/8`; результат — номер звука, переданный хвостовым переходом
в `A4C2`. Исходные вызовы `20071`: `1F3AB` передаёт 0,
`1F265` — 4, `1FC15` — 8. Отдельный вызов `1EFA5` передаёт
`A4C2` номер звука `0Bh` после шага построения строя.

| Характер `+29h` | Столбец 0 | Столбец 4 | Столбец 8 |
|---:|---:|---:|---:|
| 0 | 18 | 12 | 17 |
| 1 | 18 | 13 | 17 |
| 2 | 18 | 14 | 17 |
| 3 | 18 | 15 | 17 |
| 4 | 18 | 16 | 17 |

Все эти номера лежат в диапазоне 0..19 банка `WORK.FX`. Таблица
не содержит адресов строк CP866: это пять строк по три `u32` номера
звука. Номер 11 прямого вызова тоже относится к `WORK.FX`.

`A4C2..A4DE` берёт адрес банка из `[191E]`, ставит `EBX=0100h`,
`ECX=[EDI+20h]`, `EDX=[EDI+21h]` (центр отряда по клеткам) и
вызывает звуковой диспетчер `1416B`. Граф от `A4C2` в
`build/ai-message-a4c2-graph.md` имеет единственный внешний вызов
`1416B`; его подробный граф — `build/ai-text-queue-graph.md`
(локальные исследовательские файлы, в Git не публикуются).

## Что попадает в очередь

`1416B..141B4` возвращается без действия при выключенном звуке
`[9091]=0` или номере вне банка. Иначе выбирает вариант записи
`WORK.FX` по `(random_byte×число_вариантов)>>8` (поток `9E69`).
`1414D` ограничивает повтор одинакового указателя PCM; затем
`141B5` ищет свободный канал через `14133`. Очередь — до 255
32-байтных каналов начиная с `[70A6]`; свободный канал имеет
нулевой первый байт.

| Смещение канала | Записываемое значение |
|---|---|
| `+00` | 1: канал активен |
| `+01` | BH=1 из `EBX=0100h` |
| `+02`, `+0A` | длина PCM без старшего байта |
| `+06`, `+0E` | указатель начала/текущего PCM |
| `+12`, `+16` | X/Y центра отряда |
| `+1A` | BL=0 из `EBX=0100h` |
| `+1B` | номер звука, сохранённый через `[708E]` |
| `+1F` | старший байт исходного слова длины |

Итак, игрок слышит позиционный звуковой сигнал, если звук включён
и есть свободный канал. `A4C2` не пишет текст в память экрана,
не создаёт дипломатическое сообщение и не меняет очередь отношений.
Исполнение оригинального выбора вариантов и параметров PCM уже
проверялось `tools/verify_sound.py` (см. [sound.md](sound.md));
сам игровой путь A4C2→141B5 здесь установлен инструкциями.

Файлы `scripts/OriginalAi*.cs` и UI Claude в этом срезе не меняются.
Для подключения сигнала к игре ведущему нужен адаптер к готовым
`assets/imported/sound/work/` и правила воспроизведения в
`scripts/OriginalSoundBank.cs`. Это звуковой эффект, не строка UI.
