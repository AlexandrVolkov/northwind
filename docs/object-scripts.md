## Стандартные скрипты юнитов (ARMY__01/02.WRK)

`OriginalUnitScript` (`tools/verify_unit_scripts.py` → `tests/fixtures/unit-scripts.json`, 900 случаев, шесть точек входа): мечник/ополченец (`0`), лучник (`7F`), всадник (`4F0` в ARMY__01, `11B4` в ARMY__02). AH=0: `+0F` = 0Fh (всадник 07h), вид армии (FS:4D), первый случайный `+2E`; AH=1: перерисовка, `FS:DD` и юнит-шаг `FS:E1`; AH=2: голос (`FS:D1`). Остальные записи ARMY__01/02 (здания, рабочие, катапульта) устроены сложнее.
