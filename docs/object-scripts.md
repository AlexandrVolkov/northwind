# Сценарии объектов карты (ARMY__03.WRK)

`OriginalObjectScripts` (`scripts/OriginalObjectScripts.cs`) — скрипты ловушек и декораций; каждый сверен с x86 по 800 случаям (`tools/verify_object_scripts.py --script …` → `tests/fixtures/obj-*.json`), службы FS — записанные заглушки.

| WRK | Шаблон | Поведение |
| --- | --- | --- |
| `189` | 2 Камнепад | AH=0 `+22 = FFFFFFBF`; AH=1: на каждом 4-м случайном броске смотрит прямоугольник 4×4 клеток (`FS:14B`), при находке роняет камень (эффект 98h) в квадрате 96 px, звук 6 раз в 32 такта |
| `2B9` | 4 Каменное лицо | то же с мигающим лицом (кадры 140h..14Bh, состояния `+15`), звуки 5 и 6 |
| `3F8` | 5 Каменная стена | уходит в землю при чужом рядом (кадры 15Fh+, `+2A` до 10, `FS:157`), поднимается обратно |
| `522` | 6 Голова рыцаря | поворачивается к ближайшему врагу (`FS:14B` + `FS:15B`), моргает; мёртвая убирается (`FS:15`) |
| `624` | 7 Живая ёлка | качается кадрами 1ABh..1B6h, бьёт на 1B3h (`FS:69`) |
| `6BA` | 8 Ворон | птица: покой при AH=0, стандартный шаг юнита |
