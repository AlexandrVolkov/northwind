# Пул эффектов (LE:1 `96CD..97C6`)

`OriginalEffectPool` (`scripts/OriginalEffectPool.cs`), сверка с x86 — `tools/verify_effect_pool.py` → `tests/fixtures/effect-pool.json` (500 случаев), повтор — `tests/OriginalEffectPoolChecks.cs`.

- **`9727` (FS:19, создание эффекта).** Пределы `[18E6]`/`[18EA]` (x, y — иначе AH = FFh), бит 80h в BL обнуляет армию AL; первая свободная запись (первый байт FFh) пула `[6B2]` среди записей по `22h` байта (до `+7FDEh`; пул полон — AH = FFh); поля: `+0` тип, `+1` армия, `+5` слой (BH), `+7/+0C` позиция, `+11 = 0`; скрипт типа — `[таблица армии +0D] + 7·тип`, адрес `[+2] + [армия +9]`, вызывается с AH = 0 и тремя аргументами из стека вызывающего (EBX, ECX, EDX); верхняя отметка `[19E0]` поднимается до конца записи.
- **`96CD` (обход эффектов).** При `[1C4E] ≠ 0` для каждой живой записи (`+0 ≠ FF`) ниже отметки вызывается скрипт типа с AH = 1; затем отметка = конец последней живой записи.

Скрипты в проверке — записанная заглушка; ARMY__00..03 скрипты эффектов перенесены отдельно (`OriginalObjectScripts`, `OriginalArmy0xEffects`). Схватка пока создаёт эффекты своими списками (`Arrows`, …) — замена пулом оригинала в списке долга.
