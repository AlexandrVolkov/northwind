# Автомат движения юнита (LE:1 `9210..95D3`)

Порт `OriginalUnitMotion` (`scripts/OriginalUnitMotion.cs`), сверка с x86 оригинала — `tools/verify_unit_motion.py`, 1500 случаев, `tests/fixtures/unit-motion.json`, повтор в `tests/OriginalUnitMotionChecks.cs`.

Состояние в младшей тетраде `+2D`, запрошенное — в старшей; `+17 & 0x80` пропускает обновление.

| № | Состояние | Что делает |
|---|-----------|-----------|
| 0 | покой | при смене запроса переключение 9275; иначе возврат |
| 1 | поворот | счётчик `+26`, шаг поворота 9653 (ZF — повернулся) |
| 2 | шаг | служба 70B0; BL бит 40h — конец |
| 3 | замах | кадр `DAT[4A]·8 + курс·DAT[4B] + база`; удар на кадре `DAT[4E]` — эффект через 9727 (точка `DAT[60+2·курс]`, код `DAT[70]`) |
| 4 | перемещение | служба 12930 |
| 5 | диапазон кадров | см. docs/rufin.md (`OriginalFrameRange`) |
| 6/7 | анимация отдыха / поворот в покое | кадр `((+31>>2)·DAT[78] + +27 + 8·(DAT[4A]+DAT[4B]) + 4·ΣDAT[4F] + 0x20)` |

Состояние 0 в 92CA для юнитов игрока на границе карты вызывает D12C/10799 (событие границы, гибель 95D3). Остаточные значения AL/BL на выходе воспроизведены как у оригинала.

Статус: модуль проверен, но ещё не подключён как драйвер юнитов схватки (там пока адаптеры); подключение — следующий срез.
