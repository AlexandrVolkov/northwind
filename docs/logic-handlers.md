# Индекс обработчиков объектов

**123 шаблона, 111 отдельных пар WRK + смещение.** Это точки входа, а не количество всех функций игры или оценка готовности переноса.

Сгенерировано `tools/catalog_game_logic.py` из включённых в Git `assets/imported/templates.json` и `docs/code-analysis.json`. Индекс проверяет имя, смещение записи, указатель WRK в необработанной записи DAT и совпадение с профилем анализа. Он не декомпилирует тела функций и не доказывает смысл обработчиков.

Профиль NORWIND.EXE: `eb52f043143d763f5a595ae2175249976f278d1eebf0336ae032caf7bfa0c3a8`.

Общее устройство и статусы: [game-logic-map.md](game-logic-map.md). Совпавшее смещение внутри одного WRK означает общий вход; одинаковые числа в разных WRK не означают одинаковый код. У одинаковых имён могут быть разные обработчики. Подпрограммы, общие хвосты и параметры DAT требуют отдельного разбора.
