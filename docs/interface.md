# Интерфейс оригинала

Статус: **игровой экран переведён на графику и раскладку оригинала** (рамка, окно карты, счётчики ресурсов, миникарта, имя и шкалы выбранного, «Меню» с панелью меню, «Дипломатия» — пока без действия). Экраны меню, сохранений и карты похода декодированы, но ещё не собраны в сцены. Портреты, кнопки приказов, подсветка табличек и курсор — в MENU.SPR, формат записей не разобран.

## Как получены эталоны

Оригинал запускается в контейнере: DOSBox под Xvfb (`docs/original-launch.md`), управление — `tools/dosbox_control.sh`. Нажатие мыши нужно удерживать около 0,25 с, иначе игра его не замечает. Снимки лежат в `docs/reference/`.

Порядок экранов: видео «Бука» (INTRO.SMK) → карта мира с прокручиваемой историей Семиречья (Esc — пропустить) → **главное меню** (указатель «Игра / Выход / От авторов») → **комод с 8 ячейками** («Новая игра», колонки «Игра/Имя», шар «Выход», песочные часы) → ввод имени: игра принимает только имена героев **Олег, Игорь, Эйрик** (иначе «Такого персонажа в игре нет, смотри от авторов»; есть также «Такой персонаж уже есть» и «Герой с таким именем погиб»); клавиатура в DOS русская → **карта похода** («Старт», «Выход», компас, флажок героя) → «Загрузка эпизода» на заставке 7th Bit Labs → игровой экран.

## SCREENS.SCR

`u16` число записей, затем `u32` смещения. Запись: `u32` длина упакованных данных, `u16` ширина, `u16` высота, данные в RLE как в PCX (байт ≥ C0h — повтор следующего байта `b & 3Fh` раз; иначе один пиксель). Все 14 записей точно заполняют свои изображения. Палитры в записях нет; соответствие найдено попиксельным сравнением со снимками (средняя разница 1–2 из 255 — округление 6-битных цветов DOSBox):

| № | Размер | Что | Палитра |
| --- | --- | --- | --- |
| 0 | 640×480 | рамка игрового экрана, окно карты 16..463 | COLOR1 |
| 1 | 640×128 | заставка загрузки «7th Bit Labs» | COLOR1 |
| 2 | 176×480 | правая панель меню (Назад, Скорость: Панорама/Игра, Звук: Громкость, Реверс/Тест, Пауза, Выход) | COLOR1 |
| 3 | 176×480 | правая панель без надписей | COLOR1 |
| 4 | 640×480 | главное меню (указатель) | MENU1 |
| 5 | 640×480 | комод сохранений | MENU2 |
| 6 | 640×480 | карта похода | COLOR1 |
| 7 | 640×480 | карта мира заставки | INTRO |
| 8 | 640×480 | всадник у дерева | не подтверждена |
| 9 | 640×480 | рамка с инструментами (вероятно, «От авторов») | не подтверждена |
| 10–12 | 640×480 | камень на поляне (три варианта) | MENU1 |
| 13 | 640×480 | воин с мечом | не подтверждена |

Записи без подтверждённой палитры конвертер не выгружает. `ARMY__02.PIC` и `HELP.PIC` (32 записи) — те же записи 448×448 под окно карты (интерьер с очагом; страницы справки).

## Шрифты FNT

256 `u16` смещений; глиф: байт отступа сверху, ширина, высота, затем `ширина × высота` индексов палитры (0 — прозрачно). Кодировка CP866. Игровой экран пишет **FONT_01** с промежутком 1 пиксель: «1000» у счётчиков и имя «Олег» совпадают со снимком попиксельно. Счётчик людей — те же глифы со сдвигом индексов на −30h (красные); сдвиг подтверждён для индексов 3Dh и 50h..54h.

## Игровой экран (координаты 640×480)

| Элемент | Место |
| --- | --- |
| окно карты | 16, 16, 448×448 (14×14 клеток, без масштабирования) |
| металл, золото, дерево, люди | текст с x = 66, 159, 260, 365, y = 0 |
| «Меню» | вверху справа; открывает панель SCREENS №2 на x = 464 |
| миникарта | 488, 32, 128×128 (клетка карты — пиксель), белая рамка окна карты |
| имя выбранного | 482, 160 |
| шкалы | 572..580 и 587..595 × 176..225: рамка (146,85,0), левая заливка (65,93,48) — здоровье, правая пустая у новых отрядов |
| портрет | 482, 176 (из MENU.SPR, не разобран) |
| кнопки приказов | 4 места 484..620 × 312..390 (из MENU.SPR, не разобраны) |
| «Дипломатия» | внизу справа |
| выделение на карте | четыре зелёных (121,186,36) уголка по 4 пикселя вокруг клетки 32×32 |

Перенос: `scripts/OriginalHud.cs`, `scripts/OriginalInterface.cs`, встроено в `SkirmishMain`. Интерфейс рисуется в своих координатах 640×480 и масштабируется под окно с чёрными полями. Прежняя отладочная панель и подписи над отрядами доступны по **F1**.

Не подтверждено и помечено как временное: направление заполнения шкалы здоровья (снизу вверх); точки отрядов на миникарте; области нажатия кнопок панели меню (измерены по изображению на глаз); «Выход» из меню ведёт в лабораторную сцену, а не на карту похода; тумана войны на миникарте нет (в оригинале неразведанное чёрное); колесо мыши больше не масштабирует карту, как и в оригинале.
