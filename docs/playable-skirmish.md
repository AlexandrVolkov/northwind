# Первый играбельный срез

По F5 теперь открывается `scenes/skirmish.tscn`. Режим предназначен для короткой схватки, которую можно пройти, проиграть и повторить. Исследовательская сцена сохранена без замены её правил и доступна по F10; из неё F10 возвращает в схватку.

## Что работает

- Пять боевых отрядов из исходного SCN-слота 0: предводитель, лучник, три ополченца. Их координаты, шаблоны и относительные ссылки берутся из OBE; новая расстановка не подставляется.
- Противник — три ополченца и замок из слота 3. Выбор этих двух поселений как противников — настройка новой экспериментальной миссии, не вывод об исходной дипломатии.
- Выбор мышью/рамкой, Shift для изменения группы, Ctrl+A, групповой приказ, разные места назначения, остановка после текущего шага, камера и миникарта.
- Движение без окончания хода. Каждый маршрут разбит на шаги по 32 единицы; поворот, DAT/SEG-подготовка, дробный шаг и обновление прямоугольников занятости используют OriginalMotionPreparation и OriginalSpatialRules.
- Атака со сближением, стрельба лучника, ответные действия защитников, здоровье, уничтожение, освобождение занятости, простые визуальные эффекты ударов.
- Пауза без новых приказов, скорости ×1/×2/×4, победа после разрушения замка и уничтожения защитников, поражение при гибели предводителя, перезапуск.
- Когда замок разрушен, интерфейс показывает число оставшихся защитников, а T находит следующую цель.

## Где проходят границы точности

Начальные записи и подтверждённые ядра движения исходные. Маршрут ищет **Godot AStarGrid2D** с четырьмя соседями, эвристикой типов местности и проверкой текущей занятости; исходный планировщик маршрута ещё не восстановлен. Временная резервация следующей клетки предотвращает одновременный вход отрядов в одно место.

**30 обновлений в секунду**, скорость UI, здоровье, дальность/урон/задержки атак, выбор целей, область реакции защитников и условие победы — экспериментальные значения в `data/skirmish.json`. Это не оригинальные такты, бой или ИИ. Атаки не моделируют исходные снаряды, защиту и видимость. Уничтожение очищает клетки по ссылке объекта, но ещё не исполняет полный WRK-жизненный цикл смерти/удаления. Полная исходная цепочка владельца не используется как хранилище этого режима.

Из первой карты выбираются только перечисленные в настройках типы. Фантом, рабочие, специальные объекты, события и другие участники пока не управляются. Их исходная занятость сохраняется в загруженной сетке; это может ограничивать маршруты. Добавлен [первый цикл древесины](wood-economy.md): наём рабочих, лесопилка и доставка. Остальная экономика, наём боевых войск, сохранения и переходы пока отсутствуют.

## Изображения

`assets/imported/battle_frames.png` и JSON содержат **453** строго декодированных кадров нужных шаблонов, включая исходные кадры зданий и направлений отрядов. Это настоящий SPR, не изображение одного воина для всех типов. Кадр направления задаётся перенесённым поворотом; циклическое воспроизведение при ходьбе и экранный якорь пока экспериментальные.

Для всех участников применяется один проверенный цветовой профиль **COLOR_02.TAB + COLOR1.PAL**, с преобразованием компонентов `(v & 252) | (v >> 6)`. Принадлежность различается кольцами/полосами и миникартой. Связь исходных палитр с владельцами ещё не объявляется восстановленной.

Python-проверка сверяет новый атлас с прежними независимыми наблюдениями: 280 непрозрачных пикселей ополченца и 10 697 пикселей корпуса замка без области флагштока. Она защищает от неправильной яркости/таблицы цвета.

Готовые кадры включены в Git; на Windows не нужно запускать Python или ISO. Разработчик при изменении набора может выполнить:

```sh
python tools/prepare_skirmish_frames.py /путь/к/распакованной/игре
```

Эта команда дополняет обычный импорт. Источники SPR/PAL/TAB сохраняются только локально; в JSON записаны их SHA-256.

## Проверка

```sh
dotnet build
godot --headless --editor --path . --quit-after 120
godot --headless --path . tests/TestRunner.tscn -- simulation
godot --headless --path . tests/TestRunner.tscn -- scene
godot --headless --path . tests/TestRunner.tscn -- skirmish
python -m unittest discover -s tests -p 'test_*.py'
```

Нужен Godot 4.7.2 .NET и .NET 10 LTS. `skirmish` проверяет реальные начальные записи, групповые назначения, паузу/запрет приказов, завершение native-шага и его занятость. Сквозной прогон обычными приказами атакует поселение, затем оставшихся защитников и достигает победы с живым героем. Отдельно проверяется поражение. Сценовый тест подаёт мышиные события для рамки и ПКМ по замку.

Запуск того же теста с графическим рендерером сохраняет `build/skirmish.png` и `build/skirmish-objective.png`. Проверены загрузка кадра, цвета, видимые отряды и панель при 1280×800. Перед слиянием также проверяется запуск из чистого набора файлов Git без ресурсов исходной игры.

Первый этап рабочих, древесины и лесопилки теперь доступен; дальше — дополнительные ресурсы, фермы и ремонт. Нужен целый пользовательский цикл получения ресурса и постройки здания, с постепенной заменой временных правил на восстановленные из EXE/WRK.
